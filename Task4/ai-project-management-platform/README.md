# Task 4 — DevFlow Final Platform

The final platform integrates authentication, project management, task assignment, priorities, due dates, search/filtering, dashboard statistics, activity/audit logging, notifications, analytics, calendar/deadlines, persistent SQLite storage and local Ollama task generation.

Run from the repository root with:

```powershell
powershell -ExecutionPolicy Bypass -File ".\run-all.ps1"
```

Open http://localhost:5174.
