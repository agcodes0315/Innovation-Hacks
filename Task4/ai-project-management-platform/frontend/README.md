# Task 4 Frontend

## Run

```powershell
Copy-Item .env.example .env -Force
npm install
npm run dev
```

Open `http://localhost:5173`.

The backend must also be running on port 4000.

## Included

- Registration
- Login/logout
- Protected dashboard route
- Project create/edit/delete/details
- Task create/delete/status updates
- Priority and due date support
- Search and filters
- Dashboard statistics
- Progress bars
- Recent activity
- Loading, empty, and error states
- Responsive layout
- AI-assisted task generation UI
